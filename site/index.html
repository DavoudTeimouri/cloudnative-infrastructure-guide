      One component at a time, in order. A step marked gate must pass before the next one starts. The rollback line states what is actually possible — for Kubernetes and Ceph it is the backup, not a downgrade.

      Sources and rules

      What this site is

      A rendering of the documentation repository. The repository is the source of truth for procedures, decisions, versions and matrices. The site is generated from it and carries no independent knowledge.

      How it stays current

      • Versions are parsed from compatibility/version-matrix.md at build time.
      • Only rows marked VERIFIED are used.
      • Pages, components, steps and upgrade flows come from catalog/.
      • A build check fails when the generated data no longer matches the sources.
      • A renderer test boots this page's script in a JS engine and asserts the output.

      How to use this site

      1. Enter counts and choices in Configure.
      2. Check the generated plan and download the bundles in Review.
      3. Follow the per-step module for the long form of each procedure.

      Step modules

      Each step is a self-contained module site with client-side validation, a downloadable configuration file and a link to the authoritative document in the repository.
