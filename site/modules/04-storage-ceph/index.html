Step 04 — Storage — Ceph

Define Ceph nodes, assign roles per node, configure OSDs and pools. Validation prevents wrong configurations.

Authoritative document: storage/ceph/cephadm-deployment.md

Deployment engine

One engine per cluster, never mixed.

Nodes

Assign one or more roles per node: mon, mgr, osd, mds, rgw. Odd MON count (≥3). ≥3 OSD hosts for 3-replica. Never co-locate all MONs on one host.

Pools

Replicated pool for Kubernetes (RBD/CSI). Erasure-coded pool for bulk non-K8s data. PGs = (num_osd × 100) / replica_count, rounded up to power of 2.
